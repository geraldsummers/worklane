# Lane-local Pi collaboration

The canonical guide is [docs/agents/COLLAB.md](../../docs/agents/COLLAB.md).
The transport reference is [PROTOCOL.md](PROTOCOL.md).

Protocol v2 supports bounded interactive, planning and chat delegation in
separate no-focus workspaces. Plans are revisioned artifacts, not a permission
mode; peer messages never authorize external actions. Same-UID code is trusted.
Source/contract checks and synthetic installed acceptance do not establish
real owner subscription, service, terminal or phone delivery.
